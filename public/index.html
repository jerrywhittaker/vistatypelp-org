Create Large Print With Microsoft Word

VistaType LP is a free Windows Microsoft Word add-in for creating large print documents for paper or screen devices for readers with low vision. Additionally, it provides tools to speed the preparation of Word files for use with the BANA template for the Duxbury Braille Translator.

Download for Windows Installation guide

Free and open source · Windows + Microsoft Word 2013 or newer · No administrator rights needed

What it does

After installation, two new tabs will appear on the Word ribbon — VistaType LP and Braille Macros. The tabs are added to your existing tabs; no existing tabs are deleted.

  • Large print

    Choose font sizes from 14 to 42 points, and customize orientation, page size for paper or screen, margins, and gutter widths. Box text, reformat tables, format exercises and tables of contents, and produce fill-in lines for consumable workbooks.

  • Braille and Duxbury

    Prepares Word files for the Duxbury Braille Translator when the BANA template and SWIFT are used. Applies the correct reference page numbers for UEB and EBAE, with or without Nemeth math, and includes tools for quickly formatting foreign languages and exercises.

  • Reference page numbers

    For both large print and braille, the print book's own page numbers (reference pages) can be automatically or manually tagged for validation by the transcriber. Tools for applying appropriate styling to the tagged page numbers are available for both large print or braille.

  • Source file cleanup

    For both large print and braille, a single pass corrects common file errors — it replaces foreign styles, repairs paragraph marks, removes text boxes and frames while preserving their text, and deletes empty paragraphs and extra spaces. The result is a raw file you can actually work with.

  • Images

    For large print, pictures too large to fit within the paper or screen margins are automatically resized. Pictures can be converted to grayscale, and recurring pictures can be resized in a single pass. For braille, pictures can be preserved for examination and then removed in a single pass.

  • DAISY, NIMAS and text

    Import and repair text-based source formats, so a file that arrives as a publisher's DAISY or NIMAS export can be worked on like any other document.

A typeface that measures what it says

VistaType LP installs its own typeface, VistaTypeLP Legible, and offers it beside Tahoma when you attach the large-print template.

It exists because of a mismatch that costs a reader real size. A point size in Word sets the height of an invisible box the letters sit in — not the height of the letters. Different typefaces fill that box differently, so a face can be set at 18 point and measure closer to 16½ on a font ruler. VistaTypeLP Legible is rescaled so that the number you type, the number Word reports, and the letters on the printed page all agree.

It is built on Atkinson Hyperlegible, the Braille Institute's typeface designed for readers with low vision, and is used under the SIL Open Font License.

Download

VistaType LP installs for your own Windows account. It does not ask for an administrator password, and it does not change your ribbon.

Get the latest version

Downloads are hosted on GitHub. Take the file named VistaType LP and Braille Macros Setup, ending in .exe.

Windows may warn you. The installer is not yet code-signed, so Windows SmartScreen shows a blue “Windows protected your PC” message. Choose More info, then Run anyway. Some antivirus programs may quarantine it for the same reason.

What you need

  • Windows, with Microsoft Word 2013 or newer — Microsoft 365 is fine.
  • Word and Outlook closed before you run the installer.
  • The Duxbury Braille Translator, if you want the braille side.
